How to test

1. Upload a PDB/CIF.
2. Choose Atom / Residue / Residue window.
3. Hold left mouse near an atom and drag.
4. Release to commit one undoable command.
5. Check Console:
   provr.mouseEdit.printFirstAtoms(10)
   provr.mouseEdit.exportPDB()
   provr.mouseEdit.undo()
   provr.mouseEdit.redo()
